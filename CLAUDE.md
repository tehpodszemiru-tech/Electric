# ВИМ-ИНЖЕНЕРКА — сайт (electric.vim-scrum.ru)

Статический одностраничный лендинг для частной бригады электрики и
сантехники. Никакого бэкенда в этом репозитории нет и не должно быть.

## Структура

- `index.html` — весь сайт (HTML/CSS/JS в одном файле, стили и скрипт инлайн).
- `privacy-policy.html` — отдельная страница политики конфиденциальности.
- `assets/photos/` — фото объектов для портфолио.
- `assets/brand/logo.png` — логотип, используется и как favicon.
- `CNAME` — файл для GitHub Pages, содержит `electric.vim-scrum.ru`.
  **Не удалять и не менять без синхронной правки DNS-записи в Cloudflare.**

## Деплой

Хостинг — GitHub Pages (Settings → Pages → Deploy from branch `main` → `/root`).
Кастомный домен `electric.vim-scrum.ru` подключён через CNAME-запись в
Cloudflare (DNS only / серое облако — проксирование через Cloudflare
специально выключено, чтобы GitHub мог сам выпускать TLS-сертификат).

**Репозиторий должен оставаться публичным.** GitHub Pages на бесплатном
тарифе работает только с публичными репозиториями — если сделать репо
приватным, сайт перестанет открываться. Секретов в репозитории нет, поэтому
публичность безопасна (см. ниже).

## Секреты — где что живёт

В этом репозитории **никогда** не должно быть настоящих секретов
(API-ключей, паролей, секретных ключей форм). Обработка формы заявок
(проверка Turnstile-токена + отправка письма через Yandex SMTP) живёт
на отдельном сервере — Beget VPS (`159.194.223.147`), сервис
`electric-leads.service`, код в `/opt/electric-leads/` на сервере (локальная
копия для истории — `../electric-leads-beget`, тоже не в этом репо).
Секреты лежат в `/opt/electric-leads/.env` на сервере (права 600, только
владелец), не появляются ни в одном файле в git.

В `index.html` присутствует только **Turnstile Site Key**
(`0x4AAAAAAE665h3_Qwk-fPE_`) — это публичный идентификатор, не секрет, его
намеренно видно в исходном коде страницы.

Перед любым коммитом: если добавляешь новый скрипт/интеграцию — не вставляй
туда API-ключи, пароли, токены доступа напрямую в HTML/JS. Если для чего-то
нужен секретный ключ — он подключается через отдельный бэкенд, а не через
этот статический сайт.

## Контент — что нельзя менять без спроса

- Телефон, email, мессенджеры (MAX/Telegram) — реальные контакты бизнеса,
  менять только по явному запросу пользователя.
- Формулировки про бесплатные услуги — «бесплатный расчёт стоимости/сметы»
  можно, «бесплатный выезд» — нельзя (выезд на объект не бесплатный).
- Ссылка на Авито в футере и в блоке отличий — реальное объявление, не
  подменять плейсхолдером.

## Форма заявок

Формы (`hero-form`, `cta-form`) отправляют POST на `https://leads.vim-scrum.ru/lead`
(`WORKER_ENDPOINT` в `<script>` внизу `index.html`) — это Beget-сервер, РФ.
В каждой форме есть: honeypot-поле `website` (скрыто off-screen, для ботов)
и виджет `cf-turnstile` (антибот, Cloudflare Turnstile — только проверка
токена, персональных данных туда не уходит). Не убирать ни то, ни другое.
